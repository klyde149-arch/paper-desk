# Память ИИ-агента

Хранилище Obsidian для ИИ-агента фьючерсов Мосбиржи. Дизайн:
`docs/strategy/rf_ai_agent_design_2026-09.md` (§8). Агента пока нет — папка подготовлена заранее.

Открыть в Obsidian: «Открыть папку как хранилище» → `C:\Users\klyde\trading-sim\agent_memory`.

| Папка / файл | Кто пишет | Что читает агент |
|---|---|---|
| `Правила агента.md` | только владелец | всегда, целиком |
| `Уроки/` | агент предлагает, владелец принимает | только уроки со `status: принят` |
| `Журнал/` | код, из ответов агента | сжатую выжимку последних решений |
| `Разборы/` | агент, по субботам | нет (это отчёт для владельца) |

## Как принять урок

1. В субботу агент кладёт в `Уроки/` до двух заметок со `status: предложен`, в Telegram приходит
   сообщение.
2. Откройте заметку, поменяйте `status` на `принят` или `отклонён`.
3. Сохраните и отправьте в git (плагин Obsidian Git или `git push`). VPS подтянет изменения сам.
4. С понедельника агент учитывает принятые уроки.

Ограничения: уроки не меняют риск-рамки (они в коде), принятых уроков — не больше ~2 000 токенов,
старые уходят в `Уроки/Архив/`.
