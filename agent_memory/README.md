# Память ИИ-агента

Хранилище Obsidian для ИИ-агента фьючерсов Мосбиржи. Дизайн:
`docs/strategy/rf_ai_agent_design_2026-09.md` (§8, §15). Код агента — пакет `ai_agent/`.

Obsidian здесь **только для чтения**: всё, что меняется, меняется через Telegram или git на VPS.

| Папка / файл | Кто пишет | Что читает агент |
|---|---|---|
| `Правила агента.md` | только владелец | всегда, целиком |
| `Уроки/` | агент предлагает, владелец принимает кнопкой | только уроки со `status: принят` |
| `Журнал/` | код, из ответов агента | сжатую выжимку последних решений |
| `Разборы/` | агент по субботам, цифры считает код | нет (это отчёт для владельца) |

## Как принять урок

1. В субботу агент кладёт в `Уроки/` до двух заметок со `status: предложен`. Каждая приходит
   в Telegram отдельным сообщением с кнопками «Принять» и «Отклонить».
2. Нажмите кнопку. Ассистент запишет решение, агент на ближайшем тике (до 5 минут) поменяет
   статус в заметке и пришлёт подтверждение.
3. Принятый урок агент учитывает со следующего вызова. В каждое решение пишется версия памяти —
   так видно, помог урок или навредил.

Ограничения: уроки не меняют риск-рамки (они в коде); урок без трёх реальных случаев код
отбрасывает сам; принятых уроков — не больше ~2 000 токенов, лишние агент попросит перенести
в `Уроки/Архив/`. Файлы, начинающиеся с `_`, агент не читает.
