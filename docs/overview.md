# trading-sim / paper-desk — обзор архитектуры

Кратко: как устроена вся система, одним файлом. Детали — по ссылкам в конце.
Актуально на 2026-07-24 (дата последнего мержа в `main`; текущая ветка
`save/engines-wip-2026-07-24` — незадеплоенный снапшот, отстаёт от main).

## Что это

Локальный репозиторий `c:\Users\klyde\trading-sim` = GitHub `klyde149-arch/paper-desk`
(тот же код на VPS называется `paper-desk`, не `trading-sim` — три разных имени одной системы).
Автономный 24/7 крипто/РФ-трейдинг-бот: часть контуров бумажные (paper), часть торгует
реальными деньгами. Роль агент-сессий (Claude) — анализ и доработки, НЕ ручное ведение
цикла (этим занимается автоматика).

## Пять контуров

| Контур | Где исполняется | Движок | Универсум | Деньги |
|---|---|---|---|---|
| PAPER крипта (бенчмарк) | GitHub Actions `tick.yml`, cron */15 | `tools/auto_trade.ps1` | 19 пар (v2 «комбо») | виртуальные |
| PAPER РФ C2/C3b | внутри paper-тика | `tools/rf_engine.ps1` | 8 фьючерсов FORTS + 12 акций momentum | виртуальные, $10k×2 счёта |
| **Bybit LIVE** | VPS, таймер `live-tick` (:00) | `tools/live_engine.ps1` | 16 пар (−XRP/APT/OP/AAVE) | реальные, ~$100 |
| **RF LIVE (₽)** | VPS, таймер `live-rf-tick` (:30, антифаза Bybit) | `tools/live_rf_engine.ps1` | те же 8 фьюч + 12 акций | реальные, счёт Т-Инвестиций 2154036525, база 700k₽ |
| AI-ассистент | VPS, `trading-assistant.service` (long-polling TG) | `python3 -m assistant.bot` | — | только read-only + ручное закрытие paper-позиций по подтверждению |
| Челлендж «30 дней» | внутри paper-тика | секция в `auto_trade.ps1` | $1000, заморож. система S4, плечо 15x | виртуальные |

**Правило «двух писателей»:** paper-состояние пишет только GitHub Actions, `data/live_real/*`
— только Bybit-VPS-таймер, `data/live_rf/*` — только RF-VPS-таймер. Локальные тики с ноута
руками не запускать, пока крутится облако/VPS (иначе конфликты состояния).

## Поток данных

Ноут (dev, Claude-сессии) → `git push main` → GitHub Actions гоняет paper-тик каждые ~15 мин
и публикует дашборд на Pages. Отдельно VPS каждую минуту `git pull main`, крутит два системных
таймера (Bybit-live и RF-live, специально в разных фазах, чтобы не драться за git-lock) плюс
демон ассистента, и пушит обратно **только свои** пути состояния.

## Стратегия вкратце

**Крипта v2 «комбо»** (действует с 2026-07-10): сетап A (пробой/структура) + фильтр по BTC +
FlatMode=skip (флэт BTC на 4h запрещает входы) + фандинг-ворота ±0.05%/8ч + ATR-кэп + F&G 80/20;
риск 0.5–0.75% на сделку, ≤2–3 позиции, TP1=1.5R (50%) → безубыток → трейл EMA20 4h. Канонический
бэктест реал-универсума (16 пар): +245.8% за 6 лет, 1.65%/мес, PF 1.26, maxDD 30%.

**РФ фьючерсы (C2/C3b)**: Donchian-ядро с re-arm 10×15 + сетап A + momentum-акции, решения по
дневным барам MOEX, входы по открытию следующей сессии, стопы по касанию через часовики,
авто-финансирование рублей из USD/серебра перед сделкой.

**Челлендж**: отдельная замороженная система S4 («свип-возврат N24»), высокое плечо, форвард-тест
«с открытыми глазами» без эджа — служит контрольным примером, а не стратегией для масштабирования.

## Предохранители

- `data/HALT` (глобальный, коммит в main) — все тики выходят сразу, позиции не трогаются.
- `HALT_LIVE` / `HALT_RF_LIVE` — точечная остановка боевых контуров без входов.
- `HALT_CLOSE` / `HALT_RF_CLOSE` — принудительное закрытие (флэттен).
- Hard-halt по просадке от пика: −15%/−35% (РФ) для боевых контуров, зашито в движки.
- AI-ассистент только читает; единственное write-действие — закрытие paper-позиций через
  Telegram-подтверждение (`ASSISTANT_DRY_ACTIONS` гейтит боевой режим).
