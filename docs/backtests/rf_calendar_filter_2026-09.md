# C3b: запрет входа перед решениями ЦБ и ФРС — walk-forward

Дата: 2026-09-26. Повод: интервью по ИИ-агенту (`docs/strategy/rf_ai_agent_design_2026-09.md` §14) —
владелец согласился сначала проверить календарный фильтр обычным бэктестом, без ИИ.
Это **исследование**: боевой движок, VPS, `main` и `origin` не трогаются.

## 1. Предрегистрация (записано ДО первого прогона)

### Гипотезы

Вход в бэктесте идёт по закрытию дня сигнала. Решение ЦБ публикуется в 13:30 МСК, решение ФРС —
в 21:00/22:00 МСК, оба — до закрытия вечерней сессии (23:50). Значит, вход на закрытии дня решения
уже знает решение, а вход на закрытии **предыдущего торгового дня** проносит свежую позицию через
событие. Фильтр гасит именно такие входы: сигнал теряется, слот не занимается (как `-LongOnly`).

| Гипотеза | Событие | Инструменты | Запрещённый день входа |
|---|---|---|---|
| **H1** | решение ЦБ РФ по ключевой ставке | Si, CNY, Eu, MIX, SBRF, VTBR | последний торговый день инструмента строго до даты решения |
| **H2** | решение ФРС (FOMC) | GOLD, SILV | то же |

H1 и H2 проверяются **по отдельности** против базы. Комбинация — только если обе прошли dev.
Нефть (ОПЕК+) и газ не проверяются: у ОПЕК+ нет надёжного архива дат заседаний.

### База

Текущий C3b в каноне проекта (вариант C из `rf_july_vs_current_2026-09.md`): ядро
`-Breakout -BreakoutN 20 -AtrTrailMult 3.0 -AtrStopMult 2.0`, 11 инструментов
BR NG GOLD SILV Si CNY MIX Eu COCOA VTBR SBRF, `-StopCapPct 0.02 -RiskPct 0.005 -LongOnly VTBR,SBRF`,
без re-arm (как в каноне исследований), данные `data/moex_fut/*_1d.json` до 13.08.2026.

### Разбиение

Схема владельца «30% каждого года в резерв», в RF — помесячный вариант: **dev = январь–август,
резерв = сентябрь–декабрь каждого года** (как `slots_universe_search_2026-08.md`). Сделка относится
к окну по дню входа. Оговорка: этот резерв уже вскрывался 12.08.2026 для выбора состава корзины.
Для календарной гипотезы он остаётся проверкой вне выборки, потому что параметры фильтра на нём
не подбираются, но это не «нетронутые» данные.

### Метрика

Сумма R закрытых сделок (R = P&L / риск сделки) по окну. Дополнительно — число сделок, profit factor.

### Критерий принятия на dev (все пункты сразу)

1. Фильтр погасил **не меньше 10 входов** на dev. Меньше — «данных мало», гипотеза не принимается.
2. ΔR (фильтр − база) по всему dev **больше нуля**.
3. ΔR ≥ 0 **не меньше чем в 4 из 7** dev-лет (2020–2026).
4. Без лучшего года суммарный ΔR по dev **всё ещё больше нуля** (эффект не от одного эпизода).
5. При удвоенных расходах (FeePct 0,0005, SlipPct 0,0006, StopSlipPct 0,001) ΔR по dev **больше нуля**.

### Резерв

Вскрывается **один раз** и только для гипотез, прошедших dev. Принять, если ΔR по резерву ≥ 0.
Если ни одна гипотеза не прошла dev, резерв не вскрывается.

### Источники дат

- ЦБ: календарь решений `https://www.cbr.ru/dkp/cal_mp/` (плановые заседания 2020–2026, выгружен
  26.09.2026). Внеплановые: 28.02.2022 и 15.08.2023 — есть в календаре пресс-релизов; 08.04.2022 и
  26.05.2022 — выведены из таблицы ключевой ставки `cbr.ru/hd_base/KeyRate` как рабочий день перед
  вступлением новой ставки в силу. Проверка: все 37 изменений ставки 2020–2026 из таблицы
  сопоставлены с датой решения (не дальше 6 дней до вступления в силу). Итого 60 решений ЦБ.
- ФРС: `federalreserve.gov/monetarypolicy/fomccalendars.htm` и `fomchistorical2020.htm`. Внеплановое
  решение 3 марта 2020 (конференц-звонок 2 марта, объявление 3 марта) — датой считается 3 марта;
  15 марта 2020 (воскресенье) — последний торговый день до него 13 марта. Голосование 22.08.2025
  (notation vote) — не решение по ставке, исключено. Итого 57 решений ФРС.

Файл дат: `data/events/rf_events_2020_2026.json` (пригодится и агенту как календарь).

## 2. Результаты

**Итог: обе гипотезы не прошли dev. Резерв по предрегистрации не вскрывался. C3b не меняется.**

### Проверка инструмента

- База воспроизводит канон: 335 сделок, win 30,1%, PF 2,07, просадка 6,31% — как вариант C в
  `rf_july_vs_current_2026-09.md`.
- Регрессия выключателя: без `-BlackoutFile` выгрузки сделок и кривой капитала **байт в байт**
  совпадают с прогоном до правки скрипта (сравнение хэшей `btq_trades/equity_calf_pre` и `_calf_post`).

### H1 — перед решением ЦБ (Si, CNY, Eu, MIX, SBRF, VTBR)

| Год (январь–август) | База, сделок | База, R | Фильтр, сделок | Фильтр, R | ΔR |
|---|---|---|---|---|---|
| 2020 | 16 | +7,12 | 16 | +7,12 | 0,00 |
| 2021 | 29 | −2,20 | 29 | −2,20 | 0,00 |
| 2022 | 38 | +0,78 | 38 | +0,78 | 0,00 |
| 2023 | 23 | +12,47 | 23 | +11,67 | −0,79 |
| 2024 | 32 | +17,16 | 32 | +17,17 | 0,00 |
| 2025 | 46 | +15,86 | 46 | +15,86 | 0,00 |
| 2026 | 42 | +17,90 | 42 | +17,90 | 0,00 |
| **всего dev** | 226 | +69,08 (PF 2,10) | 226 | +68,29 (PF 2,09) | **−0,79** |

Погашено входов за весь период — 7, из них на dev 5 (CNY 2, Si 1, Eu 1, VTBR 1). Число сделок на
dev не изменилось: погашенный сигнал почти всегда повторялся на следующий день, и позиция
открывалась днём позже — уже после решения.

| Критерий | Факт | |
|---|---|---|
| 1. погашено на dev ≥ 10 | 5 | нет |
| 2. ΔR dev > 0 | −0,79 | нет |
| 3. ΔR ≥ 0 в ≥ 4 из 7 лет | 6 из 7 (нули) | да |
| 4. без лучшего года ΔR > 0 | −0,79 | нет |
| 5. удвоенные расходы: ΔR dev > 0 | −0,79 | нет |

### H2 — перед решением ФРС (GOLD, SILV)

Погашен **1 вход за весь период** (SILV, 09.12.2025 — резервный месяц), на dev — ни одного.
ΔR dev = 0,00. Не прошёл критерии 1, 2, 4, 5.

### Почему так мало

Пробой ядра C3b случается примерно на 1,8% инструменто-дней (335 входов на ~1 650 торговых дней ×
11 инструментов). Запрещённых дней у H1 около 330 (6 инструментов × ~56 решений) — ожидание
≈ 6 входов, факт 7. **Входы C3b не скапливаются перед решениями ЦБ и ФРС**, поэтому фильтр входа
почти ничего не задевает, а то, что задевает, просто переносится на день.

### Чего этот тест не отвечает

- **Позиции, которые уже открыты, проходят через решения постоянно** — C3b держит тренд неделями.
  Этот риск фильтр входа не трогает. Урезание открытых позиций перед событием — отдельная гипотеза
  (ведение позиций, а не вход), здесь не проверялась.
- Нефть и ОПЕК+, газ и запасы EIA, данные по инфляции США не проверялись (§1).

## 3. Воспроизведение

```powershell
Set-Location C:\Users\klyde\trading-sim
python tools\build_rf_event_blackout.py --group cbr_key_rate --symbols Si,CNY,Eu,MIX,SBRF,VTBR --out data\events\blackout_H1_cbr.json
python tools\build_rf_event_blackout.py --group fomc --symbols GOLD,SILV --out data\events\blackout_H2_fomc.json

# вызывать напрямую (& .\tools\...), не через powershell -File; сплаттинг хэш-таблицей в обёртке

& .\tools\backtest_rf_queue.ps1 -Breakout -BreakoutN 20 -AtrTrailMult 3.0 -AtrStopMult 2.0 -Symbols $cur `
  -StopCapPct 0.02 -RiskPct 0.005 -LongOnly VTBR,SBRF -OutTag calf_pre

  -StopCapPct 0.02 -RiskPct 0.005 -LongOnly VTBR,SBRF -BlackoutFile data\events\blackout_H1_cbr.json -OutTag calf_H1
# то же для H2 (blackout_H2_fomc.json, calf_H2) и с удвоенными расходами

python tools\analyze_rf_calendar.py --label H1 --base data\moex_fut\btq_trades_calf_pre.json `
  --var data\moex_fut\btq_trades_calf_H1.json --blocked data\moex_fut\btq_blackout_calf_H1.json `
  --base2 data\moex_fut\btq_trades_calf_base_x2.json --var2 data\moex_fut\btq_trades_calf_H1_x2.json
# --final (вскрытие резерва) НЕ запускался: ни одна гипотеза не прошла dev
```
