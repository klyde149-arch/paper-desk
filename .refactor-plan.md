# Deferred high-risk refactors

This branch intentionally contains only behavior-preserving, offline-tested
cleanup. The items below require a separate design review and an isolated
validation environment before implementation.

## Real-money crypto and RF futures

- `tools/live_rf_engine.ps1:Get-SleeveRef`: shared live-ledger accessor with
  multiple call sites. Do not inline it without state-machine regression tests.
- Real order/position fan-out and snapshot aggregation: preserve idempotency,
  halt precedence, and write ordering; test only with dedicated mock transport.
- `tools/lib_tinvest.ps1` mock-log JSON-in-JSON: changing the log shape breaks
  scenario consumers and is not a production-path optimization.

## HTTP and dashboard contracts

- `telegram-mini-app/` is untracked in this worktree. Do not modify or add it
  in this branch without the owner's explicit decision.
- A separate overview DTO could avoid reading full trade/candle histories for
  `/api/portfolios`, but must preserve current error and day-boundary semantics.
- Removing dashboard fields or Telegram launch parameters is an API/privacy
  change, not a passthrough cleanup; require versioned contract snapshots.

## Assistant safety boundaries

- Keep `list_halt_files`: it exposes halt reason/age not present in state names.
- Keep `{source, untrusted_content, data}` and capped JSON envelopes: they are
  prompt-injection and truncation boundaries, not redundant payload wrappers.

## Release gate for this branch

1. Review the three commits individually.
2. Run `python -m assistant.tests.run_all` and `tools/test_live_rf.ps1` in an
   isolated environment.
3. Do not run a real crypto/RF tick, testnet order, or deployment as a refactor
   verification step.

## Series 1 status — contract baseline

- `tools/test_tinvest_mock_contract.ps1` pins the current JSONL mock contract:
  `body` remains a JSON string inside the outer JSON record and can be parsed
  by existing scenario consumers.
- `telegram-mini-app/server/contracts.test.js` is a local, fixture-driven
  contract test for the RF and crypto dashboard DTOs. The Mini App is untracked
  in this worktree, so its test and package-script are deliberately not added
  to this Git branch until the application owner elects to version that tree.
